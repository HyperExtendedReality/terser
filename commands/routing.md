Run `terse routing $ARGUMENTS` (default to `status` if no arguments were passed; supports `on`, `off`, `model <flash_lite|flash|pro|haiku|sonnet|opus>`, `effort <low|medium|high|max|inherit>`, `verify on|off`, `check "<prompt>"`) and summarize the result. On Antigravity 2.0, you can also open the **Terser HUD** sidebar via `terser_hud` to change these interactively.
